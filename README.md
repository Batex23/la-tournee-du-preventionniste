# La Tournée du Préventionniste

Jeu sérieux (ou pas) de prévention incendie, de l'ENSOSP à Paris : commissions de sécurité ERP, feux, recherche des causes d'incendie (RCCI) et près de 900 questions PRV1 / PRV2.

**Jouer :** https://batex23.github.io/la-tournee-du-preventionniste/

Sur téléphone, ouvre le lien puis « Ajouter à l'écran d'accueil » : le jeu s'installe comme une application.

## Comment ça marche

- Ce dépôt contient uniquement le jeu (`index.html`) et les fichiers de l'application téléphone.
- Les données (questions, sauvegardes, classes, défi de la semaine, signalements des testeurs) restent dans la Google Sheet du formateur, via son script Apps Script (`Code.gs`).

## Mettre le jeu à jour

1. Sur cette page GitHub, ouvre `index.html`, puis l'icône crayon ou « Add file → Upload files ».
2. Dépose le nouveau `index.html` et valide (« Commit changes »).
3. Le jeu est à jour en une à deux minutes. Les joueurs reçoivent la nouvelle version à leur prochaine ouverture.

En cas de souci, l'onglet « History » de chaque fichier permet de revenir à une version précédente.
